    Форматирование документа

    Форматирование документа — настройка внешнего вида текста: шрифты, отступы, выравнивание и другие элементы, делающие документ понятным и аккуратным.

    Форматирование включает в себя следующие элементы:

    1. Выбор шрифта и размера: настройка типа шрифта (например, Arial, Times New Roman) и его размера для удобства чтения.
    2. Выравнивание текста: определение, как текст будет выровнен на странице — по левому, правому краю, по центру или по ширине.
    3. Отступы и интервалы: установка отступов перед абзацами, между абзацами, межстрочного интервала для улучшения восприятия текста.
    4. Цвет текста и фона: изменение цвета текста и фона документа для выделения важных частей или создания эстетичного оформления.
    5. Нумерация и маркеры: настройка нумерации и маркеров для упорядочивания информации.
    6. Добавление элементов: вставка изображений, таблиц, графиков, гиперссылок и других объектов. Фон страницы: настройка фона документа для улучшения его визуального вида.

    Шрифт

    ℹ️ Шрифт можно изменить двумя способами:

    • На вкладке «Главная».

    • Через правую кнопку мыши, выбрав «Шрифт».

    Стиль шрифта:

    1. Выделите текст, который хотите отредактировать.
    2. Перейдите на вкладку «Главная».

    3. В группе «Шрифт» выберите нужный шрифт из выпадающего списка (например, Arial, Times New Roman и т.д.).

    Размер шрифта:

    1. В той же группе «Шрифт» рядом с шрифтом есть поле для размера шрифта.

    2. Выберите нужный размер из предложенного списка или введите нужное значение вручную.

    Типы начертания (жирный, курсив, подчеркивание):

    1. Выделите текст.

    2. В группе «Шрифт» на вкладке «Главная»:

    3. Для жирного текста нажмите на кнопку B (или используйте сочетание клавиш Ctrl + B).

    4. Для курсива нажмите на кнопку I (или используйте сочетание клавиш Ctrl + I).

    5. Для подчеркивания нажмите на кнопку U (или используйте сочетание клавиш Ctrl + U).

    Выравнивание текста

    ℹ️ Текст можно выровнять двумя способами:

    • На вкладке «Главная».
    • Через правую кнопку мыши, выбрав «Абзац».

    Для этого:

    1. Выделите текст, который хотите выровнять.
    2. Перейдите на вкладку «Главная».

    3. В группе «Абзац» выберите одну из кнопок для выравнивания текста:

      • По левому краю: кнопка с иконкой выравнивания по левому краю (иконка с линиями, выровненными слева).
      • По центру: кнопка с иконкой выравнивания по центру (иконка с линиями, выровненными по центру).
      • По правому краю: кнопка с иконкой выравнивания по правому краю (иконка с линиями, выровненными справа).
      • По ширине: кнопка с иконкой выравнивания по ширине (иконка с линиями, растянутыми на всю ширину).

      • Также можно использовать горячие клавиши.

    Цвет и выделение текста

    ℹ️ Цвет текста можно изменить двумя способами:

    • На вкладке «Главная».
    • Через правую кнопку мыши, выбрав «Абзац».

    Цвет шрифта:

    1. Выделите текст, который хотите изменить.
    2. Перейдите на вкладку «Главная».
    3. В группе «Шрифт» нажмите на кнопку «Цвет текста» (иконка с буквой A и цветом под ней).

    4. Выберите желаемый цвет из предложенной палитры.

    Выделение текста цветом:

    1. Выделите текст, который хотите изменить.
    2. Перейдите на вкладку «Главная».
    3. В группе «Шрифт» нажмите на кнопку «Выделение цветом» (иконка с маркером).

    4. Выберите цвет маркера из предложенной палитры.

    Интервал и отступы

    ℹ️ Менять интервал и абзац можно двумя способами:

    • На вкладке «Главная».
    • Через правую кнопку мыши, выбрав «Абзац».

    Междустрочный интервал:

    1. Выделите текст или абзац, в котором хотите изменить интервал.
    2. Перейдите на вкладку «Главная».
    3. В группе «Абзац» нажмите на кнопку «Интервал» (иконка с двумя стрелками вверх-вниз).

    4. Выберите нужный интервал (например, 1.0, 1.5, 2.0). Более детальное изменение интервала через правую кнопку мыши, выбрав «Абзац».

    Интервал перед и после абзаца:

    1. Выделите текст или абзац, для которого нужно изменить интервал.
    2. Перейдите на вкладку «Главная».
    3. В группе «Абзац» нажмите на кнопку «Интервал» (иконка с двумя стрелками вверх-вниз).

    4. Выберите «Добавить интервал перед абзацем» или «Добавить интервал после абзаца». Более детальное изменение интервала через правую кнопку мыши, выбрав «Абзац».

    Установка отступов:

    1. Выделите абзац или текст.
    2. Перейдите на вкладку «Главная».

    3. В группе «Абзац» используйте кнопки «Увеличить отступ» или «Уменьшить отступ» для настройки отступа с левого края. Более детальное изменение отступов через правую кнопку мыши, выбрав «Абзац».

    Нумерованные и маркерованные списки

    Маркеры (Список с точками):

    1. Выделите текст или абзацы, которые хотите оформить маркерами.
    2. Перейдите на вкладку «Главная».
    3. В группе «Абзац» нажмите на стрелочку рядом с кнопкой «Нумерация» (иконка с числами 1, 2, 3).

    4. Выберите «Маркеры».

    Нумерация:

    1. Выделите текст или абзацы, которые вы хотите пронумеровать.
    2. Перейдите на вкладку «Главная».

    3. В группе «Абзац» нажмите на кнопку «Нумерация» или на стрелочку рядом с кнопкой (иконка с числами 1, 2, 3).

    Многоуровневый список:

    1. Выделите текст, который хотите оформить многоуровневым списком.
    2. Перейдите на вкладку «Главная».
    3. В группе «Абзац» нажмите на на стрелочку рядом с кнопкой «Нумерация» (иконка с числами 1, 2, 3).

    4. Выберите «Многоуровневый список» (иконка с несколькими уровнями).

    Переключение между уровнями:

    • Чтобы переключиться на более низкий уровень (например, 2.1), нажмите Tab на клавиатуре. Это сдвигирует пункт вправо.
    • Чтобы переключиться на более высокий уровень (например, 3), нажмите Shift + Tab. Это сдвигивает пункт влево.

    Настройка полей

    ❗ Размер полей указан в дюймах.

    Вы можете перевести сантиметры в дюймы с помощью онлайн-калькулятора или вручную. Чтобы перевести X сантиметров в дюймы, умножьте количество сантиметров на 0.393701: X см × 0.393701 = дюймы.

    1. Перейдите на вкладку «Разметка страницы».

    2. В группе «Поля» выберите один из предложенных вариантов:

      • Обычные — стандартные поля (верхнее и нижнее по 2 см, левое 3 см, а правое 1,5 см).
      • Узкие — поля уменьшены до 1.27 см.
      • Средние — поля среднего размера (верхнее и нижнее по 2,5 см, левое и правое 1,9 см).
      • Широкие — увеличенные поля (верхнее и нижнее по 2,5 см, левое и правое 5 см).
      • Настраиваемые поля — позволяет настроить поля вручную.

    Фон страницы

    Фон одним цветом:

    1. Перейдите на вкладку «Разметка страницы».
    2. Нажмите «Выбор цвета для фона страницы».

    3. Выберите желаемый цвет из предложенной палитры.

    Фон картинкой:

    1. Перейдите на вкладку «Вставка».
    2. Выберите «Встроенная картинка» и загрузите её с устройства.
    3. Щелкните правой кнопкой мыши по картинке, нажмите «Обтекание текстом» и выберите «За текстом».

    4. Если необходимо растяните картинку по странице.

    Колонтитулы

    ℹ️ Перейти в колонтитулы можно двумя способами:

    • На вкладке «Вставка» выбрать «Верхний колонтитул» или «Нижний колонтитул».
    • Дважды щелкнуть левой кнопкой мыши по верхнему или нижнему полю страницы, чтобы перейти в режим редактирования колонтитула.

    Вставка изображения в колонтитул:

    1. Поставьте курсор в колонтитул.
    2. Перейдите на вкладку «Вставка» и выберите «Встроенная картинка».

    3. Нажмите на картинку левой кнопкой мыши и измените её размер, растягивая или сужая её за появившуюся рамку.

    Нумерация страниц

    ℹ️ Перейти в колонтитулы можно двумя способами:

    • На вкладке «Вставка» выбрать «Верхний колонтитул» или «Нижний колонтитул».
    • Дважды щелкнуть левой кнопкой мыши по верхнему или нижнему полю страницы, чтобы перейти в режим редактирования колонтитула.

    Принцип работы:

    1. Поставьте курсор в колонтитул.
    2. Перейдите на вкладку «Вставка» и выберите «Номер страницы».

    3. Через вкладку «Главная» или правой кнопкой мыши, выбрав «Абзац», измените положение нумерации, если это необходимо.

    Дополнительные функции:

    1. Можно использовать особый колонтитул для первой страницы. Для этого, оставшись в колонтитуле на первой странице, перейдите на вкладку «Колонтитулы» и выберите значок для особого колонтитула:

    2. Можно использовать разные колонтитулы для четных и нечетных страниц. Для этого, оставшись в колонтитуле на одной из страниц, перейдите на вкладку «Колонтитулы» и выберите значок для разных колонтитулов:

    3. Можно изменить расстояние между колонтитулом и краем страницы. Для этого, оставшись в колонтитуле на нужной странице, перейдите на вкладку «Колонтитулы» и отрегулируйте расстояние. Левое поле ввода отвечает за верхний колонтитул, а правое — за нижний:

    Таблицы

    ℹ️ Таблицу удобно использовать для размещения города и даты в одной строке.

    Создать динамическую таблицу можно при помощи метки «Таблица».

    Создание таблицы:

    1. Перейдите на вкладку «Вставка».

    2. В группе «Таблицы» нажмите «Таблица» и выберите нужное количество строк и столбцов.

    Вставка данных в таблицу:

    1. После создания таблицы щелкните в ячейке и начните вводить текст.
    2. Вы можете перемещаться по ячейкам с помощью клавиши Tab (для перехода в следующую ячейку) или Shift + Tab (для перехода в предыдущую ячейку).

    Редактирование таблицы:

    • Добавление или удаление строк/столбцов:

      • Для добавления строки или столбца щелкните правой кнопкой мыши по ячейке и выберите «Вставить» — затем выберите «Вставить слева», «Вставить справа», «Вставить сверху» или «Вставить снизу».

      • Для удаления строки или столбца, выделите нужные ячейки, нажмите правой кнопкой мыши и выберите «Удалить ячейки».

    • Выравнивание содержимого ячейки:

      • Чтобы выровнять текст в ячейках, выделите нужные ячейки, щелкните правой кнопкой мыши и выберите «Выравнивание текста в ячейке», затем выберите нужное выравнивание.

    Настройка границ:

    • Добавление/удаление границ:

      • Выделите ячейки (ячейку).
      • Перейдите на вкладку «Конструктор».

      • Нажмите на кнопку «Границы».

      • Уберите или добавьте границы.

    • Изменение цвета границ:

      • Выделите всю таблицу или нужные ячейки.
      • На вкладке «Конструктор» нажмите иконку «Цвет границы» (карандаш).
      • Выберите цвет из палитры.

      • Нажмите на кнопку «Границы» и выберите те стороны ячеек, которые хотите выделить цветом.

    • Изменение типа линий:

      • Выделите всю таблицу или нужные ячейки.

      • На вкладке «Конструктор»:

        • Разверните список «Одинарный».

        • Выберите стиль (одинарный, пунктирный и т.д.)

      • Нажмите «Границы» → укажите стороны для применения

    Удаление таблицы:

    • Выделите таблицу, затем нажмите Backspace или выберите «Удалить таблицу» через контекстное меню, которое открывается правой кнопкой мыши по нажатию на таблицу.

    Разрывы

    Разрыв страницы:

    Разрыв страницы используется, чтобы начать новый раздел текста на новой странице.

    1. Поместите курсор в место, где вы хотите начать новую страницу.
    2. Перейдите на вкладку «Разметка страницы».
    3. В группе «Разрывы» выберите «Разрыв страницы».
    4. Или используйте горячие клавиши.

    Следующая страница:

    Следующая страница позволяет разделить документ на части, в которых можно использовать разные настройки для ориентации, полей или нумерации страниц.

    1. Поместите курсор в место, где хотите вставить разрыв.
    2. Перейдите на вкладку «Разметка страницы».
    3. В группе «Разрывы» выберите «Следующая страница».

    Разрыв колонки:

    Разрыв колонок используется, чтобы начать новый раздел текста с новой колонки.

    1. Перейдите на вкладку «Макет».
    2. Перейдите на вкладку «Разметка страницы».
    3. В группе «Разрывы» выберите «Разрыв колонки».

    Чётная страница:

    Разрыв «Чётная страница» начинает новый раздел на первой чётной странице. Это полезно, если нужно, чтобы раздел начинался с правой страницы на двухсторонней печати (например, если в документе используется обложка или другие элементы, требующие начала с чётной страницы).

    1. Перейдите на вкладку «Разметка страницы».
    2. В группе «Разрывы» выберите «Чётная страница».

    Нечётная страница:

    Разрыв «Нечётная страница» начинает новый раздел с первой нечётной страницы. Это также полезно для документов с двусторонней печатью, когда раздел должен начинаться с левой страницы (нечётной).

    1. Перейдите на вкладку «Разметка страницы».
    2. В группе «Разрывы» выберите «Нечётная страница».

    Ориентация страницы

    Изменение ориентации ВСЕГО документа:

    1. Перейдите на вкладку «Разметка страницы».
    2. В группе «Ориентация» выберите «Книжная» (для вертикальной ориентации) или «Альбомная» (для горизонтальной ориентации).

    Изменение ориентации ЧАСТИ документа:

    1. Выделите текст или часть документа, для которой нужно изменить ориентацию.
    2. Перейдите на вкладку «Разметка страницы».
    3. В группе «Разрывы» выберите «Следующая страница», чтобы применить разрыв раздела и изменить ориентацию только для выбранной части документа.
    4. Затем, на этой же вкладке, в группе «Ориентация» выберите «Альбомная» или «Книжная».

    Работа с изображением

    Вставка изображения с компьютера:

    1. Перейдите на вкладку «Вставка» и выберите «Встроенная картинка».

    2. Подгрузите изображение со своего устройства.

    Вставка скриншота:

    1. Сделайте скриншот с помощью Print Screen (PrtScn) на клавиатуре:
      • PrtScn — снимет весь экран.
      • Alt + PrtScn — снимет только активное окно.
      • Windows + Shift + S — позволяет выбрать область экрана для захвата (в Windows 10 и 11).
    2. После того как скриншот сделан, вернитесь в Word и вставьте его с помощью Ctrl + V
