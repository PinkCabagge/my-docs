    Метки

    Метки используются для автоматического заполнения документов. С их помощью можно подставлять данные в шаблон, задавать условия отображения информации, а также повторять части текста.

    Метки в полях

    При работе с полями мы уже сталкивались с метками:

    • Поля (Текст, Целое, Десятичное, Дата и т.д.): используется метка Значение;

    • Да/Нет: конструкция метки Условие;

    • Перечисление / Объединение: конструкция метки Выбор;

    • Список: конструкция метки Цикл.

    Добавление меток

    Способ 1.

    • Через вкладку «Метки» в верхнем меню.

    Способ 2.

    • Щёлкните правой кнопкой мыши по области редактирования и выберите пункт «Вставить метку».

    Изменение меток

    Способ 1.

    • Двойной щелчок левой кнопкой мыши по метке.

    Способ 2.

    • Щёлкните правой кнопкой мыши по метке и выберите «Значение» → «Редактировать».

    Метка «Значение»

    Используется для вставки данных из анкеты в шаблон. Позволяет отображать значения и производить над ними различные операции: вычисления, преобразование, форматирование и др.

    Поддерживаемые типы полей:

    • Текст

    • Целое число

    • Десятичное число

    • Дата

    • Время

    • Дата/Время

    • Перечисление

    • Составное поле (если внутри него есть поля из списка выше)

    ❗ Важно: не поддерживаются следующие поля:

    • Да/Нет — используйте метку «Условие».

    • Список — используйте метку «Цикл» или «Таблица».

    • Перечисление / Объединение — используйте метку «Выбор».

    Возможности:

    • Подстановка данных: имя клиента, номер договора, дату и т.д.;

    • Вычисления: сложение, вычитание, умножение, деление, больше, меньше и т.д.;

    • Применение функций: изменение регистра, склонение, форматирование даты, округление и пр.

    Синтаксис:

    Для обычного поля:

    • В метку передается идентификатор поля.

    Для вложенного поля:

    • Сначала пишется составное поле, потом вложенное — через точку.

    Метка «Условие»

    Метка «Условие» используется для логической проверки значений и управления отображением данных в шаблоне. Если условие выполняется, содержимое метки добавляется в документ, в противном случае — скрывается.

    Синтаксис

    • Обязательные параметры:

      — открывающий тег, который указывает начало условия. Внутри скобок задается логическое выражение или переменная, которая проверяется на истинность (Например: цена > 10).

      — закрывающий тег, который завершает блок условия.

    • Необязательные параметры:

      — блок, который выполняется, если условие не выполнено (ложь). Если этот параметр отсутствует в конструкции, то при невыполнении условия ничего не выводится.

    Принцип работы:

    1. Использование логических выражений

      В метке можно указывать условия, проверяющие значения полей, например:

      • Равно (=)

      • Не равно (!=)

      • Больше (>)

      • Меньше (<)

      • Логические операторы (И, ИЛИ, НЕ)

    2. Вложенные условия

      Допускается вложенность условий для проверки нескольких параметров.

    3. Использование функций

      В условиях можно применять встроенные функции, например, изменение регистра, форматирование дат, округление и т.п.

    Пример использование:

    В магазине действует скидка 10% на товары стоимостью более 10 000 рублей. Если стоимость товара 10 000 рублей или меньше, скидка не применяется.

    Шаги:

    1. Создайте поле типа «Десятичное число» с наименованием цена.
    2. Перейдите в «Метки» → «Условие» → «Если».

    3. В открывшемся окне задайте условие: цена > 10000

      Где:

      • цена — идентификатор поля.

      • > — символ «больше».

      • 10000 — пороговое значение, при превышении которого будет применена скидка.

    4. Нажмите «ОК».

    5. Установите курсор после если (цена > 10000).

    6. Вставьте метку «Значение» и укажите формулу расчета цены со скидкой:

    7. Нажмите «ОК».

    8. Для обработки случая, когда условие не выполняется, добавьте блок «Иначе».

    9. После блока «Иначе» вставьте метку «Значение». В метке укажите идентификатор поля Цена, так как скидка в этом случае не применяется.

    10. Нажмите «ОК».

    11. Завершите конструкцию, выбрав на вкладке «Метки» пункт «Условие» -> «/Если».

    Метка «Выбор»

    Инструмент, позволяющий отображать разные фрагменты текста. Её конструкция аналогична полю Перечисление, при этом она может работать не только с ним, но и с текстовым полем.

    Принцип работы:

    1. Проверяется значение указанного поля.

    2. Если значение совпадает с одним из вариантов, выводится соответствующий текст.

    3. Если совпадения нет, срабатывает блок прочее (если он указан). Если блок отсутствует — ничего не выводится.

    Синтаксис

    • Обязательные параметры:

      • — открывает блок выбора и указывает, какое поле будет проверяться.
      • и д.р. — описывает условие, при котором будет отображён связанный с ним текст.
      • — закрывает блок выбор.

    • Необязательные параметры:

      • — срабатывает, если ни один из вариантов не совпал со значением поля.

    📌 Все значения внутри вариантов должны быть указаны точно и заключены в двойные кавычки — например: вариант("ООО").

    📌 Если блок прочее не указан и не найдено совпадений — вывод не произойдёт.

    Пример использования

    Задача:

    Преобразовать текстовую оценку в числовую:

    • Отлично → 5

    • Хорошо → 4

    • Удовлетворительно → 3

    • Плохо → 2

    Шаги:

    1. Создайте поле типа «Текст» с наименованием «Оценка».

    2. Установите курсор в область редактирования, перейдите на вкладку «Метки» и выберите «Выбор» -> «Выбор».

    3. В появившемся окне укажите идентификатор поля оценка и нажмите ОК.

    4. После открытия блока вставьте первый вариант:

      • Выберите «Выбор» → «Вариант».

      • Введите "Отлично" (в двойных кавычках) и нажмите ОК.

      • После метки введите: 5.

    5. Повторите шаг для остальных вариантов:

      • "Хорошо" → 4

      • "Удовлетворительно" → 3

      • "Плохо" → 2

    6. Для обработки других значений вставьте блок «Прочее» и укажите текст по умолчанию, например: Нет оценки.

    7. Закройте конструкцию меткой /выбор.

    Результат:

    Если пользователь введёт «Отлично» — будет отображено 5. Если введено значение, которого нет среди вариантов — появится Нет оценки.

    Метка «Цикл»

    Метка «Цикл» нужна для того, чтобы автоматически повторять часть текста столько раз, сколько элементов в списке. Она берёт данные из поля типа «Список» и подставляет их по очереди, создавая, например, перечень товаров, услуг, сотрудников и т.д.

    Другими словами, если у вас есть список из нескольких значений, метка Цикл поможет вам один раз задать структуру вывода — и она сама повторит её для каждого элемента.

    📌 Часто применяется, когда нужно вывести перечень товаров, услуг, сотрудников и т.д.

    Синтаксис

    Где:

    • – начало цикла.

    • списокТоваров – идентификатор поля типа «Список».

    • данныеТовара – имя, через которое будет происходить обращение к каждому элементу.

    • обращение к конкретным данным внутри списка и составного поля.

    • – закрывает конструкцию.

    📌 Если список содержит составные поля, обращаться к ним можно через точку: товар.наименование, товар.цена и т.д.

    Принцип работы:

    1. Указывается переменная и список

      В конструкции цикла вы указываете, какая переменная будет использоваться для доступа к каждому элементу и из какого поля типа «Список» брать эти элементы:

    2. Цикл начинает перебор

      Сначала берётся первый элемент из списка. Всё, что находится внутри конструкции {цикл(данныеТовара из списокТоваров)} ... {/цикл}, выполняется один раз — с подстановкой данных этого элемента.

    3. Автоматический переход к следующему элементу

      После первого элемента цикл автоматически переходит ко второму, затем к третьему — и так до конца списка. Каждый раз используется одна и та же структура, но с подстановкой новых данных.

    4. Завершение цикла

      После того как все элементы списка обработаны, цикл завершает выполнение.

    📌 Если список пуст — ничего не выводится.

    Пример использования:

    Задача: Вывести перечень товаров с указанием названия, количества и цены.

    Шаги:

    1. Создайте поле «Список» с элементом «Составное поле».

    2. Внутри составного поля добавьте:

      • Текстовое поле — для названия товара.

      • Целое число — для количества.

      • Десятичное число — для цены.

    3. Установите курсор в область редактирования, выберите «Метки» → «Цикл» → «Цикл».

    4. Заполните параметры цикла:

      • Переменная ряда: данныеТовара (так вы будете обращаться к каждому товару внутри цикла);

      • Список: списокТоваров — идентификатор вашего списка;

      • Разделитель: можно не указывать или задать, если вы хотите, чтобы элементы разделялись запятой, точкой с запятой и т.п.

    5. Нажмите «ОК».

    6. Теперь внутри конструкции {цикл(товар из списокТоваров)}...{/цикл} вставьте текст с метками.

      Чтобы обратиться к вложенным полям каждого товара, используйте метку Значение и укажите путь:

    7. Завершите конструкцию, закрыв цикл {/цикл}.

    Метка «Таблица»

    Табличный цикл

    Если у вас в анкете есть список, и вы хотите вывести данные из него в таблицу, вам нужен табличный цикл. Он помогает автоматически создать строки таблицы — по одной на каждую запись, без ручного копирования.

    Что такое список?

    Список — это поле в анкете, куда можно добавлять несколько одинаковых по структуре записей.

    Например, если вы хотите указать сотрудников компании, вы создаёте список, а внутри каждой записи добавляете:

    • ФИО

    • Должность

    • Стаж работы

    Это называется одинаковая структура. Каждый раз вы вводите тот же набор данных — только с разными значениями.

    Что делает табличный цикл

    Табличный цикл говорит программе:

    «Возьми все записи из списка и выведи по ним строки в таблице.

Одна запись = одна строка таблицы».

    Вы настраиваете шаблон один раз, и при генерации документа программа сама создаёт нужное количество строк.

    Синтаксис

    Важно знать

    • Табличный цикл занимает целую строку в таблице.

    • Все значения из анкеты подставляются через метки.

    Где:

    • {т_цикл(сотрудник из списокСотрудников)} — начало цикла, проходящего по каждому элементу списка.

    • {списокСотрудников} — идентификатор поля «Список»;

    • {сотрудник} — переменная, через которую можно обращаться к полям одной записи;

    • {сотрудник.фио} — обращение к полю внутри списка.

    • {/т_цикл} — конец цикла.

    Принцип работы

    1. Цикл проходит по каждому элементу в списке (например, по каждому сотруднику).

    2. Берёт первую запись и подставляет её значения в строку таблицы.

    3. Повторяет строку для второй записи — и так далее, пока не обработает весь список.

    4. В результате каждая запись превращается в отдельную строку таблицы.

    Пример использования:

    Задача: Сформировать таблицу сотрудников с указанием их ФИО, должности и стажа работы.

    Шаги:

    1. Создайте поле «Список» с элементом «Составное поле».

    2. Внутри составного поля добавьте:

      • Текстовое поле — для фио.

      • Текстовое поле — для должности.

      • Десятичное число — для стажа работы.

    3. Вставьте таблицу в тело шаблона

      Через «Вставка» → «Таблица» выберите 3 столбца и 4 строки.

    4. В первой строке таблицы укажите заголовки столбцов:

    5. Во второй строке таблицы добавьте табличный цикл:

      • Переменная: сотрудник (это имя, через которое вы будете обращаться к полям внутри одной записи);

      • Список: списокСотрудников (идентификатор списка из анкеты).

    6. В последней строке таблицы закройте цикл:

    7. Внутри цикла вставьте поля через метку «Значение»:

    Табличное если

    Табличное если — это специальная метка, которая позволяет показать или скрыть строку таблицы в зависимости от условий.

    📌 Она работает так же, как обычная метка если, только предназначена именно для таблиц.

    Зачем нужно

    Иногда вам нужно выводить строку в таблице только при определённом условии. Например:

    • Показывать сотрудника только если стаж больше 3 лет.

    • Показывать товар только если цена выше 10 000 руб.

    • Показывать строку только если в анкете включена галочка.

    Вот для этого и используется метка т_если.

    Как работает

    1. Вы вставляете метку т_если в строку таблицы.

    2. Указываете в ней условие.

    3. Программа проверяет: если условие выполнено — строка отображается. Если не выполнено — строка пропускается.

    Главное:

    1. т_если работает внутри таблицы;

    2. Он показывает или скрывает всю строку;

    3. Условие можно задать по любому полю анкеты;

    4. Можно использовать внутри т_цикл, чтобы фильтровать список.

    Синтаксис

    Где:

    • {т_если(показатьДанные)} — открывающая метка, которая задаёт условие.

      • показатьДанные — это поле типа «Да/Нет» в анкете;

    • {данные.фио} — Это метка Значение, которая подставляет ФИО из списка.

      Здесь:

      • данные — переменная, ссылающаяся на текущий элемент списка (Составное поле);

      • фио — поле внутри этой записи.

    • {данные.стажРаботы} — То же самое, только подставляется значение стажа.

    • {/т_если} — закрывающая метка. Она завершает условную конструкцию.

    Всё, что между т_если(...) и {/т_если}, будет показано только если условие выполняется.

    Пример использования табличного цикла и табличного если:

    Задача: Вывести таблицу с информацией о сотрудниках, но только тех, у кого стаж работы больше 3 лет.

    Решение с использованием цикла и условия:

    1. Использование цикла (т_цикл) для перебора всех сотрудников: Мы будем использовать цикл, чтобы пройти по каждому сотруднику в списке.

    2. Использование условия (т_если), чтобы отобразить только сотрудников с стажем больше 3 лет: Внутри цикла добавим условие, чтобы выводить данные только для тех сотрудников, у которых стаж больше 3 лет.

    Шаги:

    1. Добавление таблицы:

      • Вставьте таблицу в тело шаблона (3 столбца, 6 строк).

      • В первой строке укажите заголовки столбцов: ФИО, Стаж работы.

    2. Добавление табличного цикла:

      • Объедините ячейки второй строки.

      • Вставьте метку «Табличный цикл» («Метки» → «Таблица»).

        где:

        • Переменная ряда – идентификатор составного поля (данные).

        • Список – идентификатор поля «Список» (сотрудники).

    3. Настройка условия отображения сотрудников:

      • Объедините ячейки третьей строки.

      • Вставьте метку «Табличное если» («Метки» → «Таблица») с условием данные.стажРаботы > 3.

    4. Добавление данных сотрудников:

      • В четвёртую строку вставьте значения «ФИО» и «Стаж работы» через метку «Значение»: {данные.фио}, {данные.стажРаботы}.

    5. Закрытие условий:

      • В пятой строке закройте метку «/Табличное если».

      • В шестой строке закройте метку «/Табличный цикл».

    Метка «Фрагмент»

    Метка Фрагмент позволяет вставить в шаблон другой шаблон. Это как «вложение одного шаблона в другой».

    Благодаря этой метке можно:

    Основной функционал метки «Фрагмент» заключается в возможности подгружать структуру стороннего шаблона, с использованием всего одной строки. Например, если у вас есть два готовых шаблона — «Акт приёма» и «Акт сдачи», вы можете с помощью метки «Фрагмент» структуру этих двух шаблонов подгрузить к основному.

    Данная метка подгружает уже заранее созданные шаблоны.

    Принцип работы:

    1. Путь к фрагменту – указывается источник, откуда загружается фрагмент (шаблон).

    2. Параметры – не являются обязательными. Они используются только в тех случаях, когда нужно передать во фрагмент какие-то данные. Если параметры не заданы, просто загружается сам фрагмент без дополнительной настройки.

      • Имя параметра – идентификатор поля из подгружаемого фрагмента (шаблона).
      • Выражение параметра – идентификатор поля, куда передается фрагмент шаблона, т.е. основной шаблон.

    Пример использования

    1. Откройте шаблон, фрагмент которого хотите подгрузить, например, «Акт приема». Скопируйте поля, находящиеся в анкете слева: для этого нажмите на три точки рядом с анкетой и выберите пункт «Экспорт».

    2. Перейдите в основной шаблон «Договор», нажмите на три точки слева от Анкеты и выберите пункт «Импорт».

    3. Нажмите «Выберите файл», перейдите в «Этот компьютер» -> «Загрузки». Выберите файл в формате .json и подтвердите действие.

    4. После загрузки полей в Анкету установите курсор в область редактирования, в то место, где нужно будет отображать информацию из другого шаблона.

    5. Откройте вкладу «Метки» и выберите пункт «Шаблон».

    6. В появившемся окне укажите путь к шаблону. Для этого нажмите на три точки справа от поля «Путь к фрагменту».

    7. Выберите необходимый шаблон и нажмите «ОК».

    8. Сохраните изменения и проверьте результат.

    Метка «Документ»

    Метка ОтдельныйДокумент используется для формирования набора отдельных документов из одного шаблона (например: договор, акт, счёт).

    Каждый блок, обёрнутый в эту метку, превращается в самостоятельный документ при экспорте заполненного шаблона.

    Варианты экспорта:

    • Единый файл — все документы объединяются в один .docx файл;

    • Zip-архив — каждый документ сохраняется в виде отдельного файла. Пользователь может выбрать, какие именно документы экспортировать.

    Синтаксис

    {ОтдельныйДокумент("Договор " & наименованиеДоговора)}

...текст документа...

{/ОтдельныйДокумент}

    • "Договор " — статическая часть названия документа. Указывается в двойных кавычках.

    • & — оператор конкатенации (объединения). Используется для объединения текста и значений переменных в одно имя документа.

    • наименованиеДоговора — идентификатор поля, значение которого подставляется из анкеты.

    Например: "Договор " & наименованиеДоговора может превратиться в:

    Договор Аренды, Договор Поставки и т.д.

    Пример использования

    Задача: создать шаблон, содержащий три отдельных документа: договор, акт и счёт.

    Шаги:

    1. Установите курсор перед началом текста договора.

    2. Перейдите во вкладку «Метки» и выберите: Документ → Отдельный документ.

    3. Введите название документа.

      Например:

      "Договор " & инициалы(фио, Падеж.Именительный, ФорматФИО.ФамилияИО)

      Здесь:

      • "Договор " — фиксированная текстовая часть;

      • инициалы(...) — функция форматирования ФИО;

      • фио — идентификатор поля;

      • & соединяет все части в единое имя;

      • пробел после "Договор " обязателен, чтобы слова не слились.

    4. После текста договора вставьте закрывающую метку: Документ → /Отдельный документ.

    5. Повторите те же действия для акта и счёта.

    6. Сохраните шаблон и проверьте результат при заполнении и экспорте.

    Результат

    Метка формирует отдельный документ с указанным названием при экспорте шаблона.
