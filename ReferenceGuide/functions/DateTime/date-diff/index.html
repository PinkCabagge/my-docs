    разндат

    Функция разндат используется для вычисления количества дней между двумя датами.

    Синтаксис

    разндат(начальнаяДата, конечнаяДата)

    • начальнаяДата — дата, от которой начинается отсчёт;

    • конечнаяДата — дата, до которой считается разница.

    📌 Оба аргумента должны быть полями типа «Дата».

    Пример:

    Задача: вычислить количество дней между датой заключения договора и датой его окончания.

    Шаги:

    1. Добавьте два поля типа Дата в анкету:

      • датаДоговора

      • датаОкончания

    2. В шаблоне вставьте метку Значение и выберите функцию разндат:

    3. Перейдите в меню f(x) → Дата и время → разндат

    4. В параметрах укажите:

      • Дата начала: датаДоговора (поле из анкеты)

      • Дата окончания: датаОкончания (поле из анкеты)

    5. Нажмите «ОК» — функция будет вставлена в шаблон.

    Результат

    Если дата договора = 31.03.2025, а дата окончания = 04.06.2025, то разница составит:

    65 дней
