    Функции

    Функции — это полезные инструменты, которые помогают автоматически обрабатывать данные в шаблонах. Они работают как маленькие помощники, выполняя за вас разные задачи. Благодаря функциям, шаблоны становятся «умными» — они могут подстраиваться под данные и быстро выполнять нужные действия.

    Как перейти к функциям?

    1. Дважды щёлкните левой кнопкой мыши по полю в области редактирования.
    2. В появившемся окне нажмите на кнопку f(x).
    3. Выберите подходящию функцию.

    Дата и Время

    🛑 Ошибка

    📌 Функции не будут работать, если они стоят перед форматом даты. Например: конмесяца(форматДаты(дата, ФорматДаты.ДатаКратко), 2)

    Объяснение:

    Функция форматДаты предназначена для преобразования даты в текст, например: "24.01.2025". Но когда вы используете её внутри других функций, возникает ошибка. Почему? Потому что функции датамес, конмесяца, начмесяца, разндат, смещдат работают только напрямую с датами, а текстом — нет.

    Почему это происходит?

    • Функция форматДаты превращает дату в текст, например: "24.01.2025".
    • Функции датамес, конмесяца, начмесяца, разндат, смещдат ожидает именно дату. Если ей дать текст вместо даты, она не сможет работать и выдаст ошибку.

    Как исправить?

    • Сначала используйте функции датамес, конмесяца, начмесяца, разндат, смещдат.
    • Затем примените форматДаты, чтобы корректно отобразить результат.

    форматДаты(конмесяца(дата, 2), ФорматДаты.ДатаКратко)

    дата

    Данная функция используется для задания конкретной даты на основе введённых параметров: день, месяц и год. Она может принимать как фиксированные значения (например, 12.12.2024), так и динамические данные в виде переменных (текст или целое число).

    1. Параметры:

    Функция принимает три обязательных параметра:

    • День (дд): число от 1 до 31.
    • Месяц (мм): число от 1 до 12.

    • Год (гггг): полное числовое значение года, например, 2024.

    • Типы данных:

    • Конкретные значения: вы можете указать точную дату, например, 12, 12, 2024.

    • Переменные: вместо фиксированных чисел можно использовать переменные, такие как: поле текст или целое число.

    • Результат:

    • Функция возвращает полную дату, сформированную из переданных параметров, например: 12.12.2024 00:00:00. Чтобы убрать время (00:00:00) после даты, необходимо применить функцию "Формат валюты"

    датамес

    Данная функция берёт исходную дату и сдвигает её на указанное количество месяцев вперёд или назад. Сдвиг можно задать как фиксированным числом, так и переменной, связанной с полем, значение которого будет определяться динамически.

    1. Параметры:

    2. День: исходная дата, от которой будет производиться сдвиг. Указывать нужно идентификатор поля Дата

    3. Сдвиг месяцев: Указывает, на сколько месяцев нужно сместить дату.

      • Если введено число (например, 3), дата сместится на указанное количество месяцев вперёд.
      • Если указан идентификатор поля с типом "Целое число", значение этого поля определит величину сдвига.

    4. Результат:

    5. Функция возвращает новую дату, которая соответствует исходной дате, сдвинутой на указанное количество месяцев.

    конмесяца

    Функция используется для получения последнего дня месяца, основываясь на заданной дате. Она также позволяет смещать эту дату на указанное количество месяцев вперёд или назад.

    1. Параметры:

    2. Дата (обязательный параметр): исходная дата, от которой ведётся расчёт. Где вы можете передать идентификатор поля, содержащий дату.

    3. Сдвиг месяцев (обязательный параметр): указывает, на сколько месяцев нужно сместить дату.

      • Положительное значение: сдвигает дату на указанное количество месяцев вперёд.
      • Отрицательное значение: сдвигает дату на указанное количество месяцев назад.
      • Если введено число (например, 3), дата сместится на указанное количество месяцев вперёд.
      • Если указан идентификатор поля с типом "Целое число", значение этого поля определит величину сдвига.

    4. Результат:

    5. Функция возвращает последнюю дату месяца, рассчитанную с учётом указанного сдвига.

    начмесяца

    Функция используется для получения первого дня месяца, основываясь на заданной дате. Она также позволяет смещать эту дату на указанное количество месяцев вперёд или назад.

    1. Параметры:

    2. Дата (обязательный параметр): исходная дата, от которой ведётся расчёт. Где вы можете передать идентификатор поля, содержащий дату.

    3. Сдвиг месяцев (обязательный параметр): указывает, на сколько месяцев нужно сместить дату.

      • Положительное значение: сдвигает дату на указанное количество месяцев вперёд.
      • Отрицательное значение: сдвигает дату на указанное количество месяцев назад.
      • Если введено число (например, 3), дата сместится на указанное количество месяцев вперёд.
      • Если указан идентификатор поля с типом "Целое число", значение этого поля определит величину сдвига.

    4. Результат:

    5. Функция возвращает первую дату месяца, рассчитанную с учётом указанного сдвига.

    разндат

    Функция вычисляет разность дней, месяцев и лет.

    1. Параметры:

    Функция принимает два обязательных параметра:

    • Дата начала.

    • Дата окончания.

    • Результат:

    • Функция возвращает разность двух дат.

    сегодня

    Функция возвращает текущую дату (дату, на которую производится расчёт или создание документа). Она может использоваться как самостоятельно, так и в сочетании с другими функциями и полями для автоматизации работы с датами.

    1. Особенности:

    2. Самостоятельное использование. Функция не требует ввода данных или привязки к полю. Она автоматически возвращает текущую дату. Минусом данного способа является невозможность редактировать дату.

    3. Использование в сочетании с полями. Функцию можно написать в свойствах поля (в разделе "значение по умолчанию"). В этом случае поле автоматически подставит текущую дату, с возможностью её редактирования.

    4. Функция не принимает параметры.

    5. Синтаксис:

    6. сегодня()

    7. Результат:

    8. Функция возвращает текущую дату.

    смещдат

    Данная функция позволяет смещать дату на определённое количество дней вперёд или назад. Дата может смещаться на фиксированное количество дней или меняться динамически, в зависимости от числа, введённого пользователем.

    1. Параметры:

    2. Дата (обязательный параметр): исходная дата, от которой ведётся расчёт. Где вы можете передать идентификатор поля, содержащий дату.

    3. Количество дней (обязательный параметр): указывает, на сколько дней нужно сместить дату.

      • Положительное значение: сдвигает дату на указанное количество дней вперёд.
      • Отрицательное значение: сдвигает дату на указанное количество дней назад.
      • Если введено число (например, 3), дата сместится на указанное количество дней вперёд.
      • Если указан идентификатор поля с типом "Целое число", значение этого поля определит величину сдвига.

    4. Результат:

    5. Функция возвращает новую дату, сдвинутую на указанное количество дней.

    тдата

    Функция используется для автоматического получения текущей даты и времени. Её поведение зависит от того, как она используется: с полями или без них. Она позволяет зафиксировать точное время, но возможность редактирования значения зависит от контекста её использования.

    1. Особенности:

    2. Самостоятельное использование. Функция не требует ввода данных или привязки к полю. Она автоматически возвращает текущую дату и время. Минусом данного способа является невозможность редактировать дату.

    3. Использование в сочетании с полями. Функцию можно написать в свойствах поля (в разделе "значение по умолчанию"). В этом случае поле автоматически подставит текущую дату и время, с возможностью её редактирования.

    4. Функция не принимает параметры.

    5. Синтаксис:

    6. тдата()

    7. Результат:

    8. Функция возвращает текущую дату и время.

    Логические

    если

    Функция "ЕСЛИ" — это логическая функция, которая позволяет выполнять различные действия в зависимости от результата проверки заданного условия. Она оценивает условие на истинность и возвращает одно значение, если условие выполняется (истинно), и другое значение, если условие не выполняется (ложно).

    1. Параметры:

    2. Условие:

      • Это логическое выражение, которое проверяется на истинность.
      • Оно может быть сравнением (например, A1 > 10), проверкой равенства (например, B2 = "Да") или любым другим выражением, которое возвращает истину или ложь.
      • Пример: полеПеречисление = "1 вариант".

    3. Значение истина:

      • Это значение или действие, которое выполняется, если условие истинно.
      • Может быть текстом, числом, формулой или ссылкой на другую ячейку.
      • Пример: полеТекст = "Пример текста".

    4. Значение ложь:

      • Это значение или действие, которое выполняется, если условие ложно.
      • Также может быть текстом, числом, формулой или ссылкой на другую ячейку.
      • Пример: полеЦелое = "Пример текста".

    5. Синтаксис:

    6. если(условие, значениееслиистина, значениееслиложь)

    7. Пример использования:

    8. Пример с текстом:

      • если(A1 = "Да"; "Согласен"; "Не согласен")

    9. Пример с числами:

      • если(B2 > 100; "Больше 100"; "Меньше или равно 100")

    10. Результат:

    11. Функция возвращает один из двух результатов в зависимости от выполнения заданного условия.

    Математические

    округлить

    Функция выполняет округление числового значения до указанного количества знаков после запятой.

    1. Параметры:

    2. Значение (обязательный параметр) – идентификатор поля "Десятичное число".

    3. Знаков после запятой (обязательный параметр) – количество знаков после десятичной точки, до которых выполняется округление.

      • Положительное значение: округление до указанного количества знаков после запятой.
      • Ноль (0): округление до целого числа.

    4. Результат:

    5. Функция возвращает округленное значение в соответствии с заданными параметрами.

    exp

    Функция экспоненты (exp) используется для вычисления экспоненциального роста или изменения. Проще говоря, она позволяет рассчитать, как быстро что-то увеличивается или уменьшается по мере роста значения. Основанием этой функции является число e, которое примерно равно 2.718.

    Работа функции:

    Экспонента берёт число e и возводит в степень, которую указываете. Например, если хотите возвести e в степень 2, то используете функцию exp(2), которая вернёт значение примерно 7.389.

    Если взять exp(2), это e возведённое в квадрат: 2.718^2 ≈ 7.389.

    Чем больше степень, тем быстрее растёт результат. Если же степень отрицательная, результат будет меньше единицы, что означает уменьшение или спад.

    1. Параметры:

    2. Значение (Идентификатор поля) — число, которое является показателем степени для числа e.

    3. Результат:

    4. Функция возвращает значение числа e.

    ln

    Функция логарифма (ln), или натуральный логарифм — это «обратная» операция для возведения в степень. Если известно результат числа, возведённого в степень, логарифм помогает найти степень. Основанием этой функции является математическая константа e, которая примерно равна 2.718.

    Работа функции:

    Логарифмы помогают понять, как быстро что-то растёт или уменьшается со временем, будь то деньги или рост бактерий. Это полезный инструмент для анализа процессов, которые развиваются неравномерно, например, экспоненциально.

    Если известно, что e^2 = 7.389, то ln(7.389) = 2. Это значит, что, чтобы получить число 7.389, нужно было возвести e в степень 2.

    1. Параметры:

    2. Значение (Идентификатор поля) – число, для которого нужно вычислить логарифм. Значение должно быть положительным (x>0), так как логарифм отрицательных чисел и нуля не определён.

    3. Результат:

    4. Функция возвращает результат вычисления натурального логарифма.

    log10

    Функция общего логарифма (log10), в отличие от натурального логарифма, используется для вычисления логарифма числа по любому основанию, а не только по числу e. Наиболее часто используемый вид общего логарифма — это десятичный логарифм (логарифм по основанию 10).

    1. Параметры:

    2. Значение (Идентификатор поля) – число, для которого нужно вычислить десятичный логарифм. Значение должно быть положительным (x>0), так как логарифм отрицательных чисел и нуля не определён.

    3. Результат:

    4. Функция log10(x) возвращает десятичный (декадный) логарифм числа x, то есть степень, в которую нужно возвести 10, чтобы получить x.

    Морфологические

    инициалы

    Функция «Инициалы» используется для преобразования полного имени (Фамилия Имя Отчество) в заданный формат – с сокращениями (инициалами) или без, а также в нужном падеже. Она позволяет автоматически формировать ФИО в удобном виде для документов, списков, подписей и т.д.

    ⚠️ Важно

    Если нужно склонять обычные слова или фразы, используйте функцию «Склонение», так как «Инициалы» обрабатывает только ФИО.

    1. Параметры:

    2. Выражение для имени – это идентификатор поля, откуда берется ФИО.

    3. Падеж – определяет, в какой грамматической форме будет выведено имя.

    4. Формат – задаёт, в каком виде будет представлено ФИО (с инициалами, без отчества и т. д.).

    5. Результат:

    6. Функция возвращает строку с преобразованным ФИО в зависимости от заданных параметров: падежа и формата.

    🛑 Внимание:

    Если ФИО отображается некорректно, в режиме заполнения нажмите на значок ⚙️ рядом с полем ФИО (в области редактирования). В окне «Грамматические исключения» в строке «Значение» введите ФИО в правильном падеже.

    окончание

    Функция «окончание» используется для автоматического изменения окончания слова в зависимости от рода или числа.

    1. Параметры:

    Функция принимает 5 параметров:

    • Выражение слова: идентификатор поля ФИО, по которому будет проверяться род человека (М/Ж) и число (Мн/Ед).
    • Мужской род: в данном параметре прописывают только окончание слова в кавычках. Например: "ый".
    • Женский род: в данном параметре прописывают только окончание слова в кавычках. Например: "ая".
    • Средний род: в данном параметре прописывают только окончание слова в кавычках. Например: "ое".

    • Множественное число: в данном параметре прописывают только окончание слова в кавычках. Например: "ые".

    • Синтаксис:

    • окончание(фио,"ый","ая","ой","ые")

    • Пример:

    • Уважаем{окончание(фио,"ый","ая","ой","ые")}

    • Работа с функцией:

    • Введите слово без окончания в области редактирования. Например: "Уважаем".

    • В конец написанного слова добавьте текстовое поле (например, ФИО).

    • Дважды кликните левой кнопкой мыши по добавленному полю, чтобы перейти в функции.

    • Результат:

    • Функция возвращает правильное окончание в зависимости от рода и числа.

    склонение

    Функция «Склонение» используется для изменения формы отдельных слов или целых предложений в зависимости от заданного падежа и числа.

    ⚠️ Важно:

    Функция не предназначена для работы с ФИО. Для склонения имён и фамилий нужно использовать функцию «Инициалы».

    1. Параметры:

    2. Выражение слова – это идентификатор поля, откуда берется слово.

    3. Падеж – определяет грамматический падеж, в котором будет представлено слово.

    4. Число – определяет, будет ли слово в единственном или множественном числе.

    5. Результат:

    6. Функция возвращает слово или фразу в нужной грамматической форме.

    транслит

    Функция «Транслитерация» превращает русские буквы в английские, заменяя их на похожие по звучанию символы.

    Используется для перевода текста с кириллицы (русский алфавит) на латиницу (английский алфавит).

    1. Параметры:

    2. Значения: идентификатор текстового поля, которое необходимо преобразовать.

    3. Результат:

    4. Функция возвращает текст, записанный латиницей, заменяя каждую русскую букву на соответствующий английский аналог, например, "Москва" -> "Moskva", "Привет" -> "Privet"

    форматВолюты

    Функция «Формат валюты» предназначена для форматирования числовых значений в виде денежных сумм с указанием валюты. Она добавляет разделители тысяч, округляет число до определённого количества знаков после запятой и добавляет символ валюты.

    1. Параметры:

    2. Выражение: принимает конкретное число или идентификатор поля, содержащий целое или десятичное число.

    3. Формат: определяет, как будет выглядеть отформатированная сумма.
      • Например: 1 234 (одна тысяча двести тридцать четыре) рубля 57 копеек.
    4. Падеж: указывает, в каком падеже нужно отображать валюту.

    5. Разделитель тысяч.

    6. Результат:

    7. Функция форматирует число в удобный денежный вид, добавляя валютный символ, разделители тысяч и учитывая склонение единицы измерения.

    форматДаты

    Функция «Формат даты» предназначена для форматирования даты. Она позволяет преобразовать дату в удобочитаемый текстовый формат в соответствии с выбранными параметрами.

    Функция изменяет не саму дату, а только её отображение. Например, 01.12.2023 может быть представлено как «1 декабря 2023 года», «01.12.2023» или «декабрь 2023». Используется для корректного оформления дат в документах и отчётах.

    1. Параметры:

    2. Выражение: принимает конкретную дату, заключённую в функцию дата(день, месяц, год), или идентификатор поля, содержащий дату.

    3. Формат: определяет стиль отображения даты (например, 1 декабря 2023 года, «01» декабря 2023 г., 01.12.2023).

    4. Результат:

    5. Функция берёт дату и преобразует её в заданный формат, возвращая результат в текстовом виде.

    целоеСТекстом

    форматЧисла

    Функция «Формат числа» предназначена для форматирования числовых значений, содержащихся в поле типа «Десятичное число». Она позволяет устанавливать количество знаков после запятой, настраивать разделители тысяч и дробной части, а также применять пользовательские форматы отображения чисел.

    Функция не изменяет само число, а только визуально представляет его в заданном формате.

    1. Параметры:

    2. Число: указывает, какое значение нужно отформатировать. Принимает только идентификатор поля типа «Десятичное число» или «Целое число».

    3. Свой формат: позволяет задать точный вид числа, управляя разрядами, нулями и разделителями. Доступные символы для строки формата:
      • # - разряд числа. Отображает только значимые разряды.
      • 0 - разряд числа с подстановкой 0. Если в числе цифры на этом месте нет, подставляется "0".
      • . - положение разделителя дробной части. Может присутствовать только в единственном экземпляре.
      • , - положение разделителя тысяч.
    4. Знаков после запятой: определяет, сколько знаков оставить в дробной части (например, 2).
    5. Разделитель дробной части: определяет, какой символ отделяет дробную часть.
      • . (точка)
      • , (запятая)

    6. Разделитель тысяч: определяет, какой символ разделяет тысячи.

      • " " (пробел)
      • . (точка)
      • , (запятая)

    7. Результат:

    8. Функция преобразует число в удобочитаемый формат, добавляя нужное количество знаков после запятой, разделители тысяч и правильно округляя.

    числоСТекстом

    Функция «Число с текстом» автоматически преобразует числовое значение в текст, согласуя его с указанным словом по числу и падежу, позволяя динамически изменять формы слов в зависимости от числа и формата записи (цифрами или прописью) для корректного оформления документов и текстов.

    Функция автоматически выбирает правильную форму слова (ед. или мн. число).

    1. Параметры:

    2. Выражение числа: указывает, какое число должно быть преобразовано. Принимает:

      • Конкретное число.
      • Идентификатор числовых полей.
    3. Выражение слова: определяет слово, которое изменяется вместе с числом. Принимает:
      • Простые слова указываются в именительном падеже и записываются в двойных кавычках.
    4. Формат: определяет, как будет записано число — цифрами или словами, а также влияет на его тип: количественный или порядковый.

    5. Падеж: определяет грамматический падеж, в котором будет стоять слово.

    6. Результат:

    7. Функция выводит число и слово в правильной форме с учетом грамматического падежа, формата записи числа и склонения слова, например:«5 этажей», «пять комнат».

    Работа со списками

    📌 Важно:

    • Список — это как таблица.
    • Элемент списка — это строка в таблице.
    • Выражение — это колонка с числовыми значениями.

    макс

    Функция «Максимальное» используется для поиска наибольшего значения в списке. Она применяется, когда необходимо определить максимальное число среди элементов списка, например, самую высокую цену, максимальный балл или наибольшее количество товаров.

    1. Параметры:

    2. Список: идентификатор поля, содержащего список элементов.

    3. Название элемента списка: поле внутри списка, по которому ищется максимальное значение.

    4. Выражение: указывает, какое именно значение сравнивать.

      💡 Если элемент списка является составным полем, то в выражении сначала указывается его название, затем через точку — название поля внутри него (пример: стоимость.цена), а если элемент списка не является составным полем, то выражение просто совпадает с его названием (пример: сумма).

    5. Результат:

    6. Функция возвращает наибольшее числовое значение из указанного списка.

    мин

    Функция «Минимальное» используется для поиска наименьшего значения в списке.

    1. Параметры:

    2. Список: идентификатор поля, содержащего список элементов.

    3. Название элемента списка: поле внутри списка, по которому ищется минимальное значение.

    4. Выражение: указывает, какое именно значение сравнивать.

      💡 Если элемент списка является составным полем, то в выражении сначала указывается его название, затем через точку — название поля внутри него (пример: стоимость.цена), а если элемент списка не является составным полем, то выражение просто совпадает с его названием (пример: сумма).

    5. Результат:

    6. Функция возвращает наименьшее числовое значение из указанного списка.

    срзнач

    Функция «Среднее значение» вычисляет среднее арифметическое числовых значений в указанном списке, позволяя определить среднюю стоимость и другие показатели, где необходимо усреднить данные.

    1. Параметры:

    2. Список: идентификатор поля, содержащего список элементов.

    3. Название элемента списка: поле внутри списка, по которому ищется среднее значение.

    4. Выражение: указывает, какое именно значение сравнивать.

      💡 Если элемент списка является составным полем, то в выражении сначала указывается его название, затем через точку — название поля внутри него (пример: стоимость.цена), а если элемент списка не является составным полем, то выражение просто совпадает с его названием (пример: сумма).

    5. Результат:

    6. Функция возвращает среднее арифметическое чисел из указанного списка, вычисляя его по формуле: сумма всех значений / количество элементов.

    сумм

    Функция «Сумма» вычисляет сумму всех числовых значений в указанном списке. Она используется для расчёта общей стоимости товаров, общего количества единиц, суммарных баллов и других агрегированных числовых показателей.

    1. Параметры:

    2. Список: это набор данных (например, список товаров, заказов, платежей). Принимает идентификатор поля "Список".

    3. Название элемента списка: это одна запись в этом списке (например, один товар, один заказ).

    4. Выражение: это конкретное поле в элементе списка, содержащее числовые значения, которые необходимо суммировать (например, цена, количество, сумма).

      💡 Если элемент списка является составным полем, то в выражении сначала указывается его название, затем через точку — название поля внутри него (пример: стоимость.цена), а если элемент списка не является составным полем, то выражение просто совпадает с его названием (пример: сумма).

    5. Результат:

    6. Функция проходит по всему списку, берёт из каждого элемента указанное выражение и складывает его значения.

    4. Результат:

    5. Функция возвращает количество элементов в указанном списке.
